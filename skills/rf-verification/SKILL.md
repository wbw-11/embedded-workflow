# 射频特性验证与认证流程

无线产品"功能通了"到"能过认证能上市"的差距全在这。本技能给出验证模板与认证路线。

## 一、射频特性验证（进阶仪器）

| 测试项 | 仪器 | 达标参考（消费级） |
|---|---|---|
| 发射功率 | 频谱仪/功率计 | 按认证限值（国内 2.4G 典型 ≤20dBm EIRP）留裕量 |
| 频率误差 | 频谱仪 | 晶振导致，典型 ±50kHz 内 |
| 接收灵敏度 | 信号源+误包率统计 | BLE 1M 典型 ≤-93dBm（芯片规格书为准） |
| 天线驻波比 | 网分 | ≤2.0，劣化严重查匹配电路 |

> 无仪器的替代：**选合格的认证模组**（模组厂已测完这些），整机只做"功率一致性抽检"。

## 二、实际场测模板（无仪器也能做）

| 测项 | 方法 | 判据 |
|---|---|---|
| 吞吐 | 大包 TCP/UDP 连续 1 小时 | 掉包率 <1%，无断连 |
| 距离 | 空旷地分档测（1/5/10/30m） | 参数不劣于竞品同档 |
| 穿墙 | 1~2 堵 24cm 砖墙 | 各自记录 RSSI 供对比 |
| 共存 | 同环境放 10+ 台自组网/连同一 AP | 无互扰断连 |
| 长稳 | 7×24 连续跑 | 无内存泄漏（配合 memory-leak-detection）、无累计断线 |

## 三、认证路线（按市场）

| 认证 | 适用 | 关键点 |
|---|---|---|
| **SRRC**（国内强制） | 国内销售 | 使用**有 SRRC 证的模组**做整机"模块备案"最省时；无证模组要整机送检（数周+费用） |
| FCC / CE | 出口美/欧 | 同理优先选双证模组 |
| 蓝牙 BQB（SIG） | 用"Bluetooth"商标 | 用 SIG 认证模组可免整机认证；自制设计走 QDID 引用 |
| 其它 | 按渠道要求 | 电商平台（天猫/京东）常要求提供 SRRC 证书编号 |

**核心策略（省时省钱的金律）：首选已认证模组，把认证问题前移到选型阶段**——在四步准备第二步就把"模组证书查证"列入检查项。

## 四、量产射频一致性抽检（mass-production 衔接）

- 每批次抽 3~5 片：发射功率（频谱仪）+ 频率误差 + 空口连接冒烟
- 指标超差立即停线查：贴片偏位/天线匹配器件错料/晶振不良
- 台账走 mass-production 良率表（不良现象=功率超差/连不上）

## 五、认证执行注意

- 认证条款与测试限值随法规更新，**执行时以最新标准为准**，本模板只定流程不定数值
- 送检资料通常要：原理图、PCB 版图、天线规格书、定频测试固件（认证用特殊固件：固定信道固定功率）
- 定频固件要提前准备（认证实验室常规要求），建议项目中期就做

## 六、与其它技能联动

mass-production（量产抽检衔接）/ wireless-sniffer（认证前的自主预检）/ software-design-doc（认证策略写入设计文档）/ 四步准备第二步（模组证书查证）
