# 戴维南/诺顿等效：把复杂含源网络黑盒化

## R — 原文 (Reading)

> 一个含独立电源、线性电阻和受控源的一端口，对外电路来说，可以用一个电压源和电阻的串联组合等效置换，此电压源的激励电压等于一端口的开路电压，电阻等于一端口内全部独立电源置零后的输入电阻……可先求出该一端口的开路电压、短路电流和等效电阻三个参数中的任意两个……如果需要求出第三个参数，可根据 uoc=Req·isc 计算。
>
> — 邱关源／罗先觉, 《电路》第五版 第4章 §4-3

## I — 方法论骨架 (Interpretation)

当你只关心电路里某一小片（某条支路、某个负载、某个元件的电压电流），而其余部分是一个复杂网络时，不要硬解整网方程——把「其余部分」整体黑盒成两个参数：

① **戴维南**：开路电压 uoc（端口断开时的电压）＋等效电阻 Req（独立源置零后的入端电阻），等效为「电压源 uoc 串联 Req」；
② **诺顿**：短路电流 isc（端口短接时的电流）＋Req，等效为「电流源 isc 并联 Req」。
两者用 uoc = Req·isc 互推，三个参数任取好求的两个。

关键认知：**只保证对外（端口外电路）等价，内部电压电流、内部功率绝不等价**。求参数时，独立源置零（电压源短路、电流源开路），受控源保留；含受控源时 Req 用外施电源法（端口加测试源测 V/I）求。

## A1 — 书中的应用 (Past Application)

### 案例 1: 例4-5 复杂网络求中间支路电流
- **问题**: 一个多电源网络，只需求中间电阻 R3 的电流
- **方法论的使用**: 把 R3 左、右两侧电路分别看成含源/无源一端口，求开路电压与入端电阻，塌缩成单回路
- **结论**: 原复杂网络化为「电压源 + 两个串联电阻」的简单回路
- **结果**: 直接得 i=3.53A，避免了整套网方程

### 案例 2: 例4-7 含受控源一端口的等效
- **问题**: 一端口内部含电流控制电流源 i2=0.75·i1
- **方法论的使用**: 先求开路电压 uoc=35V，再求短路电流 isc=14mA，由 uoc/isc=2.5kΩ 得 Req
- **结论**: 含受控源的线性一端口同样可等效为电压源+电阻或电流源+电阻
- **结果**: 得到戴维南与诺顿两种等效电路，定律成立

### 案例 3: 例7-4 动态电路化简（与三要素法配合）
- **问题**: 求 RL 一阶电路全响应，储能元件外电路较复杂
- **方法论的使用**: 把电感之外的部分戴维南化，得 Uoc=6V、R0=2Ω，再套三要素法
- **结论**: 等效后直接写全响应，不必解微积分
- **结果**: i2=(3−5e⁻⁰·⁵ᵗ)A

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 只关心某条支路/某个负载的电流电压，其余网络很复杂
2. 求电路的等效电阻、输出阻抗、戴维南/诺顿等效参数
3. 分析含受控源的二端网络
4. 交流/动态电路中想用等效简化（相量域、s 域通用）

### 语言信号

- "帮我化简这个电路求 X 支路电流"
- "这个网络的等效电阻/开路电压是多少"
- "用戴维南/诺顿等效"
- "output impedance / equivalent circuit / Thevenin / Norton"

### 与相邻 skill 的区分

- 与 `equivalent-transform` 的区别: 后者处理纯电阻结构化简（串并/Y-Δ），本 skill 处理含源一端口的整体黑盒化
- 与 `superposition` 的区别: 叠加是把多源分解逐一算；戴维南是把整个网络压缩成两个参数，目的不同
- 与 `max-power-transfer` 的区别: 最大功率传输依赖本 skill 求出的 Req 做匹配，是它的下游应用

## E — 可执行步骤 (Execution)

### 执行流程一览

| 步骤 | 输入 | 输出 | 出口 |
|---|---|---|---|
| 1 | 用户输入/电路 | 判定结果（是否只关心端口外部线性网络） | →步骤2 |
| 2 | 判定结果 | 方法选择（戴维南 uoc+Req 或诺顿 isc+Req） | 通常直接→步骤3；仅双方法可行且用户未指定→确认推荐方法 |
| 3 | 方法选择 | 开路电压 uoc（或短路电流 isc） | →步骤4 |
| 4 | uoc/isc | 等效电阻 Req（独立源置零/外施电源法） | 正常→步骤5；Req 不好求→先求 isc 用 uoc=Req·isc →步骤5 |
| 5 | uoc/Req/isc | 自查结果自洽（满足 uoc=Req·isc） | 正常→步骤6；仅结果存疑（负 Req/符号冲突）→确认后继续 |
| 6 | 等效参数 | 外部支路量求解结果 | 完成 |

1. **判断是否适用**
   - 完成标准: 确认只关心端口外部量、网络内含线性元件（含受控源亦可），且不会问等效内部支路量

2. **🔴 CHECKPOINT · 仅方法分叉时确认**
   - 完成标准: 判定需戴维南（求 uoc + Req）还是诺顿（求 isc + Req）时，若用户意图明确、单一方法可完成，直接进入步骤 3，不打断。
   - 判停条件: 仅当两种方法都可行且用户未指定（如"随便哪种等效都行"）、或端口结构使某方法明显更易求时，向用户说明推荐方法与理由，确认后再继续。

3. **求开路电压 uoc**
   - 完成标准: 断开端口，用结点/网孔/叠加法求端口电压
   - 判停条件: 若只求诺顿等效，可用短路电流 isc 替代本步，步骤4用 uoc=Req·isc 补

4. **求等效电阻 Req**
   - 完成标准: 独立源置零（V 短路、I 开路，受控源保留）后，对无源网络求入端电阻；含受控源时用外施电源法（加 1V/1A 测试源测 I/V），Req=V 测/I 测
   - 判停条件: 若等效力矩形不好求，先求 isc 再用 uoc=Req·isc

5. **🛑 STOP · 仅结论存疑时确认**
   - 完成标准: 求得的 uoc/Req/isc 自洽（满足 uoc=Req·isc）、与已知端口特性一致时，直接重组等效电路求解。
   - 判停条件: 仅当结果出现负数 Req（受控源）或与直觉/已知值冲突（符号方向存疑）时暂停，说明该结果的物理含义（负电阻=受控源吸收负功率的可能性）由用户确认是否接受，再继续。

6. **重组等效电路并求解外部量**
   - 完成标准: 画出「uoc 串联 Req」或「isc 并联 Req」，对关心的外部支路用欧姆/分压求解

### 失败模式速查（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 想化简后直接求等效区内部支路的电流/功率得错误结果 | 回原电路按 KCL/KVL 求该支路量，勿用等效模型 | 网络太复杂时改用 `superposition` 拆源或 `kirchhoff-laws` 列网方程 |
| 算出的 Req 为负或与端口直觉冲突 | 检查是否含受控源，用外施电源法重求 Req 并复核符号方向 | 负电阻=受控源吸收功率，说明物理含义后由用户确认是否接受 |
| 遗漏受控源控制量跨到端口外部 | 从原电路定位控制量所在支路补写其约束方程 | 只求与控制量无关的外部量，或转交 `method-selection` 重列方程 |
| 开口就先列整套网方程，没先判断只需外部量 | 先问清用户要的是不是内部量，不是则走戴维南黑盒化简 | 确需内部量时改用 `kirchhoff-laws` 列方程求解 |

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要求等效区内部某支路的电流/功率（内部不等效，须回原电路）
- 网络含非线性元件（戴维南只对线性等效成立）
- 端口内含受控源且其控制量在端口外部（受控量跨网时需另行确认）

### 作者在书中警告的失败模式

- 「对外等效」被误当「内部也等效」——求内部量出错
- 开口就列网方程，而不是先判断"只需外部量"从而化简

### 作者的盲点 / 时代局限

- 教材以手算为主，未展开受控源负电阻（Req<0）在现实中的含义与稳定性边界
- 未讲等效模型在噪声/非线性失真分析中的局限

### 容易混淆的邻近方法论

- 与 `max-power-transfer`：匹配是下游应用，不要把"求匹配"当本 skill 本身
- 与 `equivalent-transform`：后者为纯电阻结构化简，无「开路电压」概念
