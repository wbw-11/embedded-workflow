# 芯片系列规则管理

## 适用场景

- 开始新的芯片项目（确定该芯片属于哪个系列，加载对应 L2 规则）
- 切换开发板 / 芯片（从 GD32 切到 STC8 或 ESP32）
- 写外设驱动、寄存器配置、ISR 代码之前
- 新增或更新某个芯片系列的规则

## 规则三层体系（权威定位）

本技能只负责 **L2 芯片系列层**。三层归属的判断标准：**换芯片后这条规则还成立吗？**

| 层级 | 适用范围 | 判断标准 | 存放位置 |
|------|----------|----------|----------|
| L1 全局层 | 所有芯片 | 换任何芯片都成立 | `user_profile.md`（四步准备流程、版本管理、止损规则、代码风格等） |
| L2 芯片系列层 | 同架构芯片 | 换同架构芯片成立 | 本技能 `rules/` 目录 |
| L3 芯片型号层 | 单颗芯片/单项目 | 只对该芯片成立 | 各项目的 `project_memory.md` |

**冲突裁决**：L3（型号级，最具体）> L2（系列级）> L1（全局级）。三条同时加载，具体优先。

## 芯片系列 → 规则文件映射表

| 芯片 / 板子 | 系列 | 内核 | 规则文件 |
|------|------|------|----------|
| GD32F4xx（gd32f407zgt6 等） | ARM Cortex-M | Cortex-M4 | `rules/arm_cortex_m.md` |
| STM32F4xx / F1xx 等 | ARM Cortex-M | Cortex-M0~M7 | `rules/arm_cortex_m.md` |
| STC8H8K64U / STC15 | 8051 | 8051 | `rules/8051_mcs51.md` |
| ESP32-S3 / ESP32-WROOM | ESP32 | Xtensa LX7 | `rules/xtensa_esp32.md` |
| ESP32-C3 | ESP32 | RISC-V（非 Xtensa） | `rules/xtensa_esp32.md`（内核差异见该文件注意事项） |

## 加载流程

1. **确定当前芯片**（按优先级）：
   - ① 调用 `board-config` 技能 → `switch-board -Current` 读取 `$env:CURRENT_BOARD`
   - ② 从当前工作目录路径推断（如 `...\GD32F407VE\...`）
   - ③ 仍不确定 → 询问用户当前芯片型号
2. **查映射表**，确定芯片所属系列和规则文件
3. **读取对应的 `rules/<系列>.md`**，将规则应用于当前任务
4. **同时检查 L3 型号级约束**：按以下优先级搜索当前项目的 `project_memory.md`，如有型号级硬约束（引脚表、特定寄存器序列等），以 L3 为准（L3 > L2 > L1）：
   - ① `<项目工作目录>`（当前打开的物理工程目录）
   - ② `<memory_root>/projects/<项目名>/`（记忆系统项目记忆目录）
   - ③ 两处都没找到 → 告知用户 L3 缺失，建议在项目目录下新建 `project_memory.md` 记录引脚表、踩坑记录等单项目专用约束
5. L1 全局规则（user_profile.md）始终生效，无需重复加载

## 与其他技能的联动

| 技能 | 与本技能关系 |
|------|--------------|
| board-config | 提供当前芯片/板子（本技能的加载入口） |
| datasheet-lookup | L2 规则要求"寄存器不凭记忆"，具体查阅走该技能 |
| pin-check | L2 要求 GPIO 引脚检查，具体冲突检测走该技能 |
| embedded-dev-rules | L2 规则与开发红线（改 .h 查引用等）叠加生效 |

## 维护指南

### 新增一个芯片系列

1. 在 `rules/` 下新建 `<系列名>.md`，参考现有文件的章节结构（工具链/时钟/中断/内存/寄存器/GPIO/系列踩坑/与L3关系）
2. 在映射表中新增一行
3. 内容必须来自已验证的经验或官方文档，不接受未经验证的推测（用户强制要求）

### 规则升级：L3 → L2

当某个项目 `project_memory.md` 里的踩坑/约束**换芯片后仍可能成立**时，提炼进对应系列的 `rules/` 文件，并在 L3 中标注"已上升为 L2"。

### 删除规则

确认该规则已无价值或已被新规则覆盖时删除，避免规则库膨胀。

## 验证

- 映射表每个系列都有对应规则文件
- 对任意给定芯片型号，能按加载流程唯一确定规则文件
- 规则文件内容与 user_profile / 官方文档一致（抽查核对）
