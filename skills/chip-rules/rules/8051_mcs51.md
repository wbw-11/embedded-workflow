# 8051 / MCS-51 系列规则（L2 芯片系列层）

> 适用范围：STC8H8K64U、STC15 等 8051 内核芯片（Keil C51 开发）。型号级约束以各项目 `project_memory.md`（L3）为准。

## 工具链

- 编译：Keil C51（动态检测路径，优先环境变量 `KEIL_ROOT` → 注册表 → 候选路径；当前验证路径 D:\Keil_v5\C51\BIN\C51.exe），链接 BL51/LX51，产物 `.hex`（无 axf）
- 编译方式：必须 **Rebuild All**，禁止增量编译
- 开发方式：STC 库函数或寄存器开发均可（两种都验证过）
- 版本归档：编译通过后自动复制 `hex`（+ `omf`/`map` 如有）到 `<项目根>/Firmware_Build/Vxx/`，命名 `<芯片>_Vxx.hex`（如 STC8H8K64U_V12.hex）。详细规则见 user_profile「固件版本管理」章节（L1 强制，全局通用）

## 时钟

- **默认内部 IRC**，不同型号 IRC 频率不同（STC8H 常见 24MHz，需查手册）
- 使用外部晶振前必须验证起振（同 ARM 规则：视觉 + 万用表 + 用户确认）

## 中断

- 中断向量编号固定（IE/IP 寄存器），优先级不可配置或有限（部分型号可设，查手册）
- ISR 内禁止 printf/耗时操作等红线见 user_profile「嵌入式代码审查最佳实践」（L1），此处不重复

## 内存

- **大端字节序**（与 ARM 小端相反，移植时注意）
- 存储类型：`data` / `idata` / `xdata` / `code`，需显式声明
- 内存模型：small / compact / large，与 RAM 大小匹配
- 8 位数据类型（u8/u16）与 ARM 的 uint8_t 不同，移植需调整

## 寄存器

- 用 `sfr` / `sbit` 定义特殊功能寄存器与位
- **寄存器名因型号而异**（STC8H 与 STC15 可能完全不同），不能直接搬代码，按 datasheet-lookup 查阅

## GPIO

- 4 种模式：准双向 / 推挽 / 开漏 / 高阻，通过 PnM0/PnM1 配置
- 上电默认准双向，高电平驱动能力弱，驱动 LED 等需配推挽

## 系列踩坑

- 软浮点，浮点运算慢
- 外部晶振起振慢/失败常见，先跑内部 IRC 验证程序再切晶振
- 引脚复用寄存器（如 ADC/串口切换）配置错误最常见
- **通用驱动防坑规则**（底层优先验证 / 官方例程基线对照 / 不改官方库源码 / 3 版本止损红线）见 user_profile.md「嵌入式驱动开发防坑规则」章节（L1 全局强制，对 STC8/8051 官方库同样适用）
