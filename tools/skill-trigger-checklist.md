## 使用说明

1. **单条单会话**：每条话术开新会话发，避免一次触发多个技能或上下文干扰
2. **判定标准**：回复出现该技能**专属特征**（非泛泛而谈）即为命中
3. **漏触发处理**：把原话发给助手，助手对该技能 description 补触发词后重测
4. **状态更新**：验证通过后把该行"状态"改为 "✅ 已验证"
5. **背景**：2026-09-06 全部技能 description 已压缩（9671→3525 字符 / 约省 8.8K token 每会话），本清单用于事后回归确认触发无损
